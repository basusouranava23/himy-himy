# FPS Calculator

A tiny web app that converts between **Frames Per Second (FPS)** and **Frame Time (milliseconds)**.

## Features
- Enter FPS to get the corresponding frame time.
- Enter frame time to get the corresponding FPS.
- Real‑time, bidirectional conversion.
- Responsive design powered by Tailwind CSS.

## How to Run

1. **Download / clone the repository.**
2. Open `index.html` in any modern web browser.

No build tools or server required.

## Project Structure

- `index.html` – Main HTML file with Tailwind CDN.
- `styles.css` – Minimal custom styling.
- `script.js` – JavaScript handling the conversion logic.
- `README.md` – This file.

Enjoy quick FPS calculations!
